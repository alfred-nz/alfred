# Provenance

Alfred was built by Team Odin at Junction 2026 as part of BlueSight (junction-demo/bluesight), the team's entry for
Stoa's "Make Blueprints Talk" challenge. All hackathon assets, including the Alfred character artwork and animation
components (AlfredCharacter, ButlerHandsAndProps, ButlerPropsSvg, useAudioLipSync and their type definitions), are
released under the MIT License; see [LICENSE](LICENSE).

This desktop version adapts that Alfred for OpenExec. No browser profile, credentials, invoices, application state or
private conversation data are included.
